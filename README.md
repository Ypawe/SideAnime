# SideAnime — başlangıç sürümü

## yerelde çalıştırma
1. zip dosyasını çıkar.
2. VS Code ile `SideAnime` klasörünü aç.
3. `index.html` dosyasını tarayıcıda açabilir veya VS Code Live Server eklentisini kullanabilirsin.

## GitHub Pages ile yayınlama
1. GitHub'da `sideanime` adında yeni bir **public** repository oluştur.
2. bu klasördeki `index.html`, `styles.css` ve `app.js` dosyalarını repository'nin köküne yükle.
3. repository → Settings → Pages bölümüne gir.
4. Build and deployment altında `Deploy from a branch` seç.
5. Branch olarak `main`, klasör olarak `/ (root)` seç ve Save'e bas.
6. birkaç dakika sonra GitHub Pages adresin görünür.

## notlar
- bu sürüm demo anime verileriyle gelir; puanlar ve bölüm sayıları örnek veridir.
- bölüm sayfaları ve oynatıcı alanı çalışır ancak gerçek video kaynağı bağlanmamıştır.
- favoriler bu tarayıcıdaki localStorage alanında saklanır.
- GitHub Pages statik hostingdir; tek başına hesap sistemi veya özel veritabanı sağlamaz.
- kendi haklarına sahip olduğun ya da yayınlama iznin bulunan video kaynaklarını kullan.
